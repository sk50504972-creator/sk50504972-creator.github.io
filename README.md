# 발해손해사정주식회사 순천지점 공식 홈페이지

정적(static) 단일 페이지 홈페이지. GitHub Pages로 24시간 호스팅한다.

- 공개 주소: https://balhae.claimworks.kr/
- 빌드 과정 없음. `index.html` 하나만 수정하면 push 즉시 반영된다(보통 1~2분).

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 홈페이지 본체 (HTML+CSS+JS 단일 파일, 외부 의존 없음) |
| `site_spec.json` | 홈페이지 기획 스펙 원문 (섹션·문안·디자인 요구사항) |
| `robots.txt` | 검색엔진 수집 허용 + 사이트맵 위치 |
| `sitemap.xml` | 검색엔진 제출용 사이트맵 |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 비활성화 |

## 수정 방법

```bash
# 1. 내용 수정
#    index.html 편집

# 2. 로컬 확인
python -m http.server 8790 --bind 127.0.0.1
#    → http://127.0.0.1:8790/

# 3. 배포
git add -A && git commit -m "수정 내용" && git push
#    → 1~2분 뒤 https://balhae.claimworks.kr/ 에 반영
```

## 아직 채워야 할 항목 (플레이스홀더)

`index.html` 안에서 `확인 후 기입` / `입력 필요` / `tbd` 클래스로 표시된 곳:

- [ ] 대표 전화번호
- [ ] 카카오톡 채널 ID
- [ ] 이메일 주소
- [ ] 손해사정업 등록번호
- [ ] 지도 임베드 (카카오맵 / 네이버지도)
- [ ] 상담 폼 접수 엔드포인트 — **현재는 전송되지 않는다.** 입력 검증만 동작한다.
- [ ] 실적·사례 섹션 — 실제 사건 자료를 익명화·비식별화한 뒤 채운다. 확인되지 않은 실적은 게시하지 않는다.

## 주의

- 게재 문안에 개인정보·특정 보험사 비방·과장 실적을 넣지 않는다.
- 소비자선임권 설명은 일반 제도 안내이며, 개별 사안의 요건·기간은 약관 기준으로 확인한다.
